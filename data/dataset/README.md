# GTA-NarrativeTraj — dataset (story-mode)

- `gtanarrativetraj_full_events.csv` — full event-level log.
- `gtanarrativetraj_storymode_events_by-real-date/` — daily splits + `MANIFEST.csv`.
- `gtanarrativetraj_full_events_cutscene_soundfile.xlsx` - cutscene soundfiles matched and verified
  - codes/data used for this purpose is under GTA-NarrativeTraj/data/codes_cutscene and /cutscene_text_files
  - `gtanarrativetraj_full_events_cutscene_soundfile_verification_process.xlsx` - the file used to verify matched cutscene soundfiles
- `gtanarrativetraj_full_events_cutscene_soundfile_missingfiles_verified.xlsx` - some of the missing soundfiles were also verified

Schema highlights are described in the paper; column names in the CSVs match the paper tables.
